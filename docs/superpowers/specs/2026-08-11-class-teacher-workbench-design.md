# 班主任智慧工作台 · 设计规格

日期：2026-08-11
状态：已获用户认可，待实现

## 一、产品定位

长沙公办小学六年级班主任的智慧班级管理工作台。响应式 Web 应用（手机 + 电脑浏览器均可使用），左侧常驻深藏蓝纵向侧边栏 + 顶部全局状态栏 + 卡片式内容区。所有学情数据、学生信息、工作台账均为可自由编辑的模板，演示数据使用随机生成的姓名与家长电话以保护学生隐私。

**已确认的关键决策：**
- 纯小学版：移除 PRD 中所有高中模板残留（太原高一、选科走班、强基培优、新高考、心理辅导台账等）。
- 侧边栏共 17 项菜单。
- 技术栈：React + Next.js（App Router + API Routes）+ better-sqlite3（SQLite 文件数据库）+ Tailwind CSS + Recharts。
- 部署：本机运行、免登录，绑定 0.0.0.0，手机连同一 Wi-Fi 通过 `http://电脑局域网IP:3000` 访问。
- 交互：所有数据单元格「点击即编辑、失焦/回车自动保存」，乐观更新 + 失败回滚。

## 二、整体架构

```
Next.js（App Router，单进程）
├── app/layout.tsx          整体壳：左侧深藏蓝侧边栏 + 顶部状态栏 + 内容区
├── app/(pages)/<页面>      17 个页面（客户端组件，路由切换）
├── app/api/[资源]/route.ts REST CRUD 接口（GET/POST/PUT/DELETE）
├── lib/db.ts               better-sqlite3 单例：建表 + 首次种子数据
├── components/             通用组件（内联编辑、卡片、图表、表格、模态框、toast）
├── lib/                    数据访问、类型定义、随机数据生成器
└── data/app.db             SQLite 文件，首次启动自动生成
```

- 顶部状态栏：左侧班级名称下拉选择框（可编辑模板，如「长沙 XX 小学六年级（X）班」）；右侧日期时间；页面右上角统一【新增 / 导出 / 编辑】湖蓝底功能按钮。
- 图表使用 Recharts（柱状图、环形饼图、分数段直方图）。
- 生产运行：`next build` 后 `next start`（绑定 0.0.0.0）；开发运行：`npm run dev`。

## 三、数据模型（SQLite 表）

首次启动自动建表并灌入种子数据。所有表主键 `id`（INTEGER PRIMARY KEY AUTOINCREMENT），时间字段统一 TEXT（YYYY-MM-DD）。

### 3.1 基础与设置
| 表 | 字段 | 说明 |
|---|---|---|
| `settings` | `key` TEXT PK, `value` TEXT | 键值对：班级名称、班主任姓名、总人数、男女人数、年级班次、教室行列数等 |
| `students` | 姓名、性别、家长电话、班干部职务、小组编号、学生层次、是否下午托、备注 | 学生主档，约 45 条种子数据 |
| `classroom_config` | 行数、列数、讲台位置 | 排座位布局 |

### 3.2 考勤与纪律
| 表 | 字段 | 说明 |
|---|---|---|
| `leave_records` | 学生id、假别（事假/病假/公假）、事由、开始日期、结束日期、时长 | 请假台账 |
| `discipline_records` | 日期、学生id、类别、违纪内容、处理方式 | 违纪台账 |

### 3.3 学情与作业
| 表 | 字段 | 说明 |
|---|---|---|
| `grades` | 考试名称、学科（语数英）、学生id、分数 | 成绩明细 |
| `homework` | 学科、布置日期、作业要求、截止时间、已交数、迟交数、未交数、未交学生名单 | 作业台账 |

### 3.4 时间与日程
| 表 | 字段 | 说明 |
|---|---|---|
| `schedules` | 日期、标题、任务类型（备课/教研/培优/监考/会议等）、时长、完成状态 | 日程安排 |
| `timetable` | 星期（1-5）、节次、学科、是否语文课 | 周课表 |
| `todos` | 标题、日期、状态（待办/已完成/逾期）、优先级 | 待办事项（仪表盘卡片 + 快捷「添加待办」） |

### 3.5 育人记录
| 表 | 字段 | 说明 |
|---|---|---|
| `conversations` | 日期、学生id、主题、内容、谈话效果 | 谈话记录 |
| `home_visits` | 日期、学生id、方式（家访/电话/家长会）、内容、是否参会 | 生涯家访 |
| `evaluation` | 学生id、维度（品德/学习/体育/美育/劳动）、得分、评语 | 综合素质评价 |
| `parent_comm` | 日期、学生id、方式（电话/微信/面谈）、内容 | 家校沟通 |
| `safety_logs` | 日期、类别（课间/交通/食品/消防/防溺水/其他）、内容、处理情况 | 安全台账 |
| `peiyou_records` | 学生id、学科、薄弱点、目标分数、辅导记录 | 培优临界生台账 |

### 3.6 工作留痕
| 表 | 字段 | 说明 |
|---|---|---|
| `work_logs` | 日期、事项、类型（班级管理/教学教研/家校沟通/学生培优/生涯活动/安全教育/会议培训/心理辅导）、地点、时长 | 工作纪实 |

## 四、17 个页面设计

### 4.1 仪表盘（首页）
- 上方 2 排信息卡片（PRD 2×3 宫格 + 扩展）：班级基础信息 / 当日考勤 / 本周常规违纪 / 待办事项（含逾期预警）/ 作业收缴率 / 最近单元测平均分 / 本月工作留痕 / 家校沟通台账。
- 下方快捷操作宫格 12 项：记违纪、布置作业、请假登记、工作留痕、谈心谈话、录入成绩、添加待办、发布家校通知、日程安排、班级排位、学生档案、家访记录。点击跳转对应页面或打开录入弹窗。

### 4.2 日程安排
- 顶部统计面板：本周备课/教研/培优/监考/会议总量。
- 分类标签筛选。
- 时间轴清单：每条含标题、类型标签、时长，右侧青绿完成勾选；全部可编辑。

### 4.3 我的课表
- 顶部汇总：每周总课时、语文任教课时。
- 周课表网格：周一~周五 × 早读/正课/中午托/下午托，语文课时蓝色高亮。
- 底部课时分布条形图。

### 4.4 学生管理
- 基础面板：总人数/男/女/班干部/临界关注数量。
- 检索筛选：性别、下午托、学生层次。
- 学生列表：姓名、班干部职务、家长电话、小组编号、违纪累计条数；点击即编辑、可新增删除。

### 4.5 成绩分析
- 顶部考试筛选（单元小测1/2/3…）+ 语数英切换。
- 数据卡片：平均分、及格率、优秀率、最高最低分。
- 分数段直方图；学生成绩明细表（可编辑）。

### 4.6 作业管理
- 统计面板：累计布置总量、平均提交率、累计未交人次。
- 作业列表：学科、布置日期、作业要求、截止时间、红色收缴进度条、已交/迟交/未交人数、未交学生名单。
- 配套按钮：【录入收缴情况 / 编辑 / 删除】。

### 4.7 请假管理
- 统计板块：累计请假、当日请假、本月人次、病假占比。
- 请假台账列表：学生、假别（事/病/公）、事由、时长、离返日期；可编辑新增。

### 4.8 违纪台账
- 统计：累计/本周/本月条数；类别筛选。
- 记录列表：日期、学生、类别、违纪内容、处理方式。

### 4.9 谈话记录
- 记录列表：日期、学生、谈话主题、内容、谈话效果；支持新增编辑。

### 4.10 生涯家访
- 统计：家访次数、家长会场次、家长会参会率。
- 家访记录列表 + 家长会记录。

### 4.11 综合素质评价
- 五大维度（品德/学习/体育/美育/劳动）逐生打分表格 + 评语栏；顶部按维度汇总图表。

### 4.12 排座位
- 教室布局面板：行列数可配、讲台区域标注、双人课桌。
- 点击座位弹出学生选择器换人，支持整排换组。

### 4.13 家校沟通
- 沟通记录列表（日期、学生、方式、内容）+ 发布家校通知入口。

### 4.14 安全台账
- 类别：课间/交通/食品/消防/防溺水/其他；台账列表（日期、类别、内容、处理情况）。

### 4.15 培优临界生台账
- 临界生名单（学生、学科、薄弱点、目标分数、辅导记录），支持从成绩分析一键标记临界生。

### 4.16 工作留痕
- 数据面板：累计记录数、累计时长。
- 八大类（班级管理/教学教研/家校沟通/学生培优/生涯活动/安全教育/会议培训/心理辅导）环形饼图。
- 工作纪实台账列表：日期、事项、类型、地点、时长。

### 4.17 系统设置
- 班级基础信息编辑（班级名称、班主任、年级班次等）。
- 种子数据重置（一键重新随机生成演示数据）。
- 数据导出/备份：下载 SQLite 文件或 JSON。
- 界面主题微调。

## 五、视觉规范

- 侧边栏底色：深空藏蓝；页面基底：浅灰白；功能卡片：纯白圆角矩形（微圆角 8px）、扁平化。
- 功能色映射：
  - 蓝色 → 学情成绩、学情研判；青绿色 → 考勤、常规纪律；紫色 → 待办任务、家校事项；橘黄/琥珀 → 家访、家长会、学生沟通；红色 → 作业管控、临界生跟踪；明黄 → 预警标记。
  - 课表学科单元格蓝色高亮标注语文授课课时。
- 功能按钮：主操作统一湖蓝底白字；任务完成标识青绿勾选图标；预警类明黄警示三角。
- 图表配色：柱状图、环形饼图、分数段直方图统一规范，语数英各用区分色。
- 左侧菜单栏：简约线性教研教育图标 + 文字组合，线条干净克制；禁止卡通化、二次元美术风格；文字工整清晰。

| `InlineEdit` | 点击即编辑核心组件：点击变输入框 → 失焦/回车自动保存 → 乐观更新，失败回滚 + toast |

| `ChartCard` | 图表容器 |
| `Modal` | 表单弹窗 |
| `Toast` | 保存成功/失败反馈 |
| `EmptyState` | 空状态占位 |

## 七、数据流

- 页面挂载 → `GET /api/[资源]` → 渲染。
- 编辑 → `PUT /api/[资源]/[id]`，乐观更新本地 state，失败回滚 + toast。
- 新增 → `POST`；删除 → `DELETE`（带确认弹窗）。
- 仪表盘聚合数据：由 `/api/dashboard` 一次性返回各统计项。

## 八、错误处理与测试

- API 层统一 try/catch，返回 `{ error: string }`；前端统一 toast 提示。
- 数据库文件不可写/不可初始化时，启动阶段给出明确提示。
- API CRUD 用 vitest + 临时 SQLite 文件做单元测试。
- 页面通过 `next build` 校验 + 浏览器手动冒烟。
- 种子数据脚本幂等（不重复灌入）。

## 九、种子数据

首次启动自动生成：
- 约 45 名学生：随机百家姓姓名（姓与名分开随机组合）、性别均衡、随机家长电话（13x 开头）、小组编号 1-6、层次（优/良/合格/关注）、是否下午托、随机班干部（班长/学习委员/纪律委员/课代表等）。
- 一周课表（含语文课时）、当月日程、近期作业与收缴情况、请假、违纪、一次或多次单元测成绩、工作留痕、家访、谈话等演示记录。
- 系统设置提供一键重置重新生成。

## 十、运行方式

- 开发：`npm run dev`
- 生产：`npm run build && npm start`（绑定 0.0.0.0）
- 手机访问：同一 Wi-Fi 下 `http://<电脑局域网IP>:3000`
